# 고등학교 학점 배당표 검증기

교육과정 기준 과목과 교육감 승인 과목을 대조해 학점 배당표의 **D열 과목명**, **M열 비고**를 확인하는 Streamlit 앱입니다.

## 기능

- 업로드한 `.xlsx`/`.xlsm` 파일에서 시트와 `D=과목`, `M=비고` 헤더를 감지합니다.
- 고등학교 교과 및 과목 검증 기준의 표 1~3과 교육감 승인 과목 목록을 독립적으로 조회합니다.
- 표 2는 `특목고 선택 과목`, 표 3은 `전문 교과` 표기가 M열에 있는지 확인합니다.
- 승인완료 서울특별시교육청 과목은 `교육감 승인 과목`, 타 시·도교육청 과목은 `타 시·도 교육감 승인 과목`으로 확인합니다. 전문으로 판정되는 승인 과목은 `(전문)`을 붙입니다.
- 결과를 `정상`, `오류`, `확인 필요`로 나누고 판정 근거·요구 비고·후보 안내를 CSV로 내려받을 수 있습니다.

## 과목명 일치 규칙

과목명 끝의 `*`, `**`만 비교 전에 제거합니다. 이외의 공백, 기호, 숫자, 로마자 차이는 자동 보정하지 않습니다. 유사 후보는 참고 정보일 뿐 자동 일치로 판정하지 않습니다.

## 로컬 실행

Python 3.10 이상 권장.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/build_reference_catalog.py
streamlit run app.py
```

브라우저에서 Streamlit이 출력한 로컬 주소를 엽니다.

## Streamlit Community Cloud 배포

1. 프로젝트를 GitHub 저장소에 올립니다.
2. Streamlit Community Cloud에서 해당 저장소와 `app.py`를 선택합니다.
3. `requirements.txt`를 기준으로 의존성을 설치해 배포합니다.
4. 기준 문서와 승인 과목 CSV는 `data/` 안에 포함되어야 합니다.

현재 프로젝트에는 사용자가 제공한 기준 문서와 2026-11-08 교육감 승인 과목 CSV가 함께 들어 있습니다. 새 자료를 받으면 원본 파일을 `data/`에서 교체한 뒤 `python scripts/build_reference_catalog.py`를 실행하세요.

## 자료 및 개인정보

기준 자료의 출처·유의사항은 `data/고등학교교과및과목검증기준.md`에 포함되어 있습니다. 앱은 업로드 파일을 읽기 전용으로 처리하며 앱 코드에서 업로드 파일을 디스크에 저장하거나 외부 서비스로 전송하지 않습니다. 다만 실제 공개 배포 시에는 Streamlit 호스팅 환경의 접근·보관 정책을 별도로 확인하세요.
